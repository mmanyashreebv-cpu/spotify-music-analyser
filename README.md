# Spotify Music Analyser

## About the Project
Spotify Music Analyser is a MATLAB-based project that analyses music data and presents the results through an interactive dashboard.

## Features
- Top 10 popular songs
- Genre analysis
- Danceability and energy comparison
- Search songs by title or artist
- Music insights and statistics
- Spotify-inspired dashboard design

## Technologies Used
- MATLAB
- MATLAB code (`.m` files)
- CSV dataset

## How to Run
1. Download or clone this repository.
2. Open MATLAB.
3. Open and run `SpotifyDashboard.m`.
4. Select the Spotify tracks CSV dataset when prompted.
5. Explore the charts and music insights.

## Project Files
- `SpotifyDashboard.m` — Main interactive dashboard.
- `main.m` — Additional music analysis code, if applicable.
- `spotify_tracks.csv` — Music dataset, if included.
